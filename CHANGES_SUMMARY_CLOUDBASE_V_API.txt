================================================================================
API Key 获取优先级
================================================================================

优先级 1（最高）：用户在 UI 中提供的 API Key
  └─ 来源：localStorage (userVApiConfig?.apiKey)

优先级 2：环境变量
  ├─ VITE_V_API_GPT_IMAGE_2_API_KEY（GPT Image 2）
  └─ VITE_V_API_SEEDREAM_4_5_API_KEY（Seedream 4.5）

优先级 3：本地配置文件
  └─ src/lib/api-keys.local.ts

优先级 4（最低）：CloudBase 云函数
  ├─ 函数名：getVApiKey
  ├─ 环境变量：V_API_KEY
  └─ 自动调用时机：前三个来源都不可用

如果都无法获取 → 抛出错误，提示用户配置 API Key

文件：src/lib/cloudbase.ts
───────────────────────────
行号范围：84-115
变更类型：新增函数

添加的函数：getVApiKeyFromCloudFunction()
- 功能：从 CloudBase 云函数获取 V-API Key
- 返回类型：Promise<string | null>
- 主要步骤：
  1. 获取 CloudBase App 实例
  2. 确保用户已匿名登录
  3. 调用 "getVApiKey" 云函数
  4. 验证返回值结构
  5. 返回 API Key 或 null
- 错误处理：catch 块记录错误并返回 null

================================================================================
性能考虑
================================================================================

首次调用延迟：+100-500ms
  原因：需要调用 CloudBase 云函数

缓存策略：不缓存
  原因：确保获取最新的 Key，提高安全性

优化空间：可以添加短期缓存
  建议：如果性能要求高，可以缓存 5-10 分钟

================================================================================
安全建议
================================================================================

✅ 推荐做法：
  - 使用 CloudBase 存储敏感信息
  - 定期轮换 API Key
  - 监控云函数调用日志
  - 限制云函数访问权限

❌ 不要做的：
  - 在前端代码中硬编码 API Key
  - 在 localStorage 中暴露敏感信息（已通过 UI 控制）
  - 共享云函数的环境变量配置
  - 无限制地暴露云函数接口
