🎯 用户流程示意图

  场景 1: 新用户注册
  
    打开应用 → [认证页面]
              → 点击"注册"
              → 输入邮箱 → 发送验证码 → 邮箱接收
              → 输入验证码 → 设置密码 → 完成注册
              → [自动登录] → [进入应用]
              → 显示欢迎信息和登出按钮

  场景 2: 已有账户登录

    打开应用 → [认证页面]
              → 点击"登录"
              → 输入用户名/邮箱 + 密码
              → 点击登录 → [验证成功]
              → [进入应用]
              → 显示欢迎信息和登出按钮

  场景 3: 用户登出

    在应用中 → 点击顶部"登出"按钮
             → [会话清除]
             → [返回认证页面]
             → 可重新登录
